# 胡同 × 唱片店 × 小型 Live House v1

## 设计结论

把下一阶段定在 **2006 年前后、鼓楼片区的虚构小胡同**。唱片店不是孤立房间，而是胡同里一间沿街门脸，后面借用一进小院和一间由旧台球厅/酒吧改成的小型现场空间。时间点比 2003 更适合同时容纳实体唱片、独立摇滚和 live house：D22 的公共记忆属于 2006–2012，而北京 live house 在 2003 年已经从咖啡/酒吧形态长出来。

空间叙事关键词：**窄巷、低檐、院门、门脸、唱片、海报、声音泄漏、邻里生活、临时演出**。

## 背景依据

- 北京胡同由连续的四合院和低层平房形成；保护规划强调保持胡同的走向、宽度和尺度，主要胡同一般大于 7m，次要胡同小于 7m，传统平房以 1–2 层为主。我们的主巷取 5.2m，支巷取 2.8–3.6m，保持低矮、转折和半室外灰空间。
- 1990s–2000s 的实体音乐消费并非只有“淘打口碟”。北京唱片店会按独立厂牌、电子、实验、摇滚/民谣、爵士/布鲁斯分类，店里有试听、拆封、标价和店员整理唱片的工作痕迹。
- 北京 live house 早期常从咖啡、酒吧、台球厅等既有小空间进入；小场地的关键体验是门口抽烟闲聊、狭窄走廊检票买酒、贴满海报的入口、观众和乐手近距离共处。舞台不应像大型音乐节，而应像一间被声音撑满的旧房子。

## 场景分区

1. **主胡同 / 入口**：低檐、灰砖、旧门牌、自行车、树荫和邻居生活。玩家先听到很弱的鼓声，再看到唱片店的橱窗。
2. **唱片店门脸**：约 30–40㎡，沿墙分类货架，中央两组可绕行唱片箱，窗边试听位，后侧收银台。分类牌用手写/打字机风格，陈列允许“有秩序的凌乱”。
3. **小院过渡**：唱片店后门通向一个 45–60㎡ 的天井，晾衣杆、纸箱、饮料箱、海报墙和临时检票桌把日常生活与演出连接起来。这里是路线的第二个分叉点。
4. **小型 Live House**：约 80–120㎡，容纳 60–100 人；低舞台、鼓组/音箱、短吧台、灯控/调音台和一条后台侧通道。观众可从侧面绕到舞台边缘，形成近距离观看点。
5. **后巷 / 屋顶出口**：演出结束后的安静区，能看到屋檐、旧砖墙和远处城市光；作为情绪收束和下一场景出口。

## 玩家路线

- **A 进入**：从主胡同进入，先经过橱窗与门口海报；玩家可以直接进店，也可以绕门口自行车和邻居摊位观察。
- **B 逛唱片**：进入唱片店后，中央唱片岛形成环形动线；左侧是摇滚/独立厂牌，右侧是电子/爵士，后侧收银和试听桌作为视觉锚点。
- **C 发现声音**：玩家在试听位听到后院传来的鼓点，触发“声音泄漏”事件；店员给出两条信息：找演出海报、把一张唱片送到后台。
- **D 进入小院**：从店后门出来，路线分成“检票桌”与“后台侧门”。检票桌通向观众区，后台侧门通向乐手/器材路线；两条路线在舞台侧边重新汇合。
- **E 观看演出**：观众区不是单向通道，玩家可以在吧台、后排、舞台侧边三个观察点切换。灯光和音量随位置变化，靠近舞台更强、更红，后排更暗、更能看到人群。
- **F 离场**：演出结束后，主门暂时拥挤，玩家可走后巷上一个低矮屋顶/平台，听到胡同夜声，最后从另一扇门回到城市。

### 路线原则

- 至少两次可选择的分叉：唱片店中央环岛、院子里的检票/后台分叉。
- 每个空间都提供“看、听、摸/拿”的对象，避免单纯向前走。
- 用声音先于视觉提示下一空间：唱片店听到低频，院子听到试音，live house 门缝看到频闪光。
- 每个区有一个可记忆的视觉锚点：橱窗唱片墙、收银台绿灯、院子海报墙、低舞台红灯、后巷屋檐。

## Blender / Meshy 组装策略

所有可见几何继续只使用 Meshy 资产；Blender 负责尺寸、旋转、重复、UV/材质重映射、灯光和相机。下一轮按“可重复模块”生成与装配：

- **胡同壳体**：灰砖墙、白灰墙、门楼、影壁、檐口、旧窗、雨水管、路面砖。
- **生活层**：自行车、煤球/饮料箱、晾衣杆、旧三轮车、盆栽、门帘、居民杂物。
- **唱片店层**：门脸、橱窗、分类唱片架、中央唱片箱、试听桌、收银桌、纸箱和价签。
- **现场层**：低舞台、鼓组、吉他/贝斯、音箱、麦克风、调音台、短吧台、检票桌、海报墙。
- **叙事层**：演出 flyer、手写价格卡、试听耳机、待上架纸箱、后台 setlist、门票和贴纸。文字只做贴图，几何来自 Meshy 卡片/框架。

### 打光

- 胡同：蓝灰天光 + 屋檐遮挡，主路不要平均亮。
- 唱片店：橱窗冷光、收银台偏黄、试听台局部暖光；中央唱片岛上沿有窄条补光。
- 小院：一盏摇晃的门灯 + 演出海报反光，保留暗部。
- Live House：舞台红/琥珀侧光、观众区低照度、吧台绿色小灯，频闪只做局部动画。
- 后巷：月色蓝光 + 远处城市橙光，作为情绪缓冲。

## Unity 场景拆分建议

可以先保持一个可加载的 `D22_HutongMusicBlock` 主场景，再把内容按可验证单元拆成 Prefab/子场景：

- `Hutong_Approach`：入口巷道与邻里生活，验证第一印象和分叉。
- `RecordShop_2006`：沿用唱片店 v4 的资产，但改成临街门脸和后门。
- `Courtyard_Transition`：院子、检票桌、海报墙，验证声音泄漏和任务触发。
- `LiveHouse_Backroom`：小舞台、观众区、吧台和后台通道，验证循环观看路线。
- `Hutong_NightExit`：后巷/屋顶平台，验证出口情绪和下一场景连接。
