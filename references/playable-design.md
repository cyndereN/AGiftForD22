# 走调长镜头 · 可玩设计补充 v3

日期：2026-09-25。基于用户提供的 GDD v2.0 和 Walk Demo 研究。本文是供讨论与开发的新增设计，保留原 GDD，不覆盖原文件。具体时长、门槛、音高和尺寸均为可修改的原型起点。

## 一句话体验

带着一台旧录音机穿过演出前的房间和街巷，把微弱声源收进一卷磁带；城市随声部增加而变化，最后让原本零散的声音成为一场合奏。

## 保留与补充

保留 GDD 第 2.2 节：Livehouse／电子管吉他功放 → 胡同／盘式机 → 唱片行／双唱机 → 体育场／主控台。声音仍按 Notes → Riff → Drums & Texture → Full Ensemble 演进。便携 Recorder 贯穿所有地点。

新增：每关 3 个明确互动单元、一个可见的声音目录、统一的录音确认反馈、一个 8–12 分钟的首关测试切片。原文第 1.1 节较宽泛的街角／地下室等场景作为后续扩展，不扩大本轮范围。

叙事提案：开场一张胶带便条“空轨留着，回来一起放”。不指定真实音乐人为任务 NPC，不编造真实演出事件。故事通过搬运设备、借线、递唱片和试听等细节表达社群。主线不是修复一个废墟，而是参与一个正在使用的音乐空间。

## 两层界面，一条主循环

默认在连续空间中走近声源，单击进入设备近景；镜头短距离滑入，返回原站位。PC 原型默认 WASD／鼠标漫游，E 或单击交互，Tab 打开采样目录，Esc 返回。预留“点击声源自动走近”的可访问模式；首轮无需同时实现两套移动系统。

采样目录覆盖在场景上，显示地点和录音格。未进入的地点显示轮廓、名称与需要的声部，不展示虚假的已探索照片。完成条件会自动计入，即使玩家没有预先选中目标；选中目标仅改变追踪提示，避免忘记选格导致劳动丢失。

循环：发现声源 → 尝试一个手势 → 捕捉稳定片段 → 保存新声音 → 下一小节加入配器 → 看见下一处声源。没有失败扣分，没有有限电量，没有资源花掉后的软锁。退出操作保留已保存采样，未确认录制可重新尝试。

## 进度与解锁

- 收藏不消耗，录入依据唯一 sample_id 去重。首次确认录制增加 1；重复试听和重新调音不会增加收集数。
- Livehouse：N01、N02、N03 共 3 个单音，3/3 后开放胡同。
- 胡同：保留 3 个单音，新收 R01、R02、R03 共 3 个 Riff，3/3 后开放唱片行。
- 唱片行：新收 D01、D02、T01（两个节奏层、一个纹理层），3/3 后开放终章。
- 体育场：把四类声部装入主控台，完成总混音与录制。终章有 3 个动作单元，不额外伪造 3 个采样。
- UI 分别显示“独立声音 0–9”和“本地点 0–3”，不把重复演奏次数做成货币。四关通关标记单独保存。
- 某项卡住时可提示手势、扩大稳定区或启用一键辅助录制；结果一样，不损失内容。

## 12 个互动单元

### 第一关 Livehouse · 先让房间响起来

**L01 / 第一次通电**。近景功放、靠箱放的吉他、接线。点开关后点一次琴弦；开关、灯、弦和喇叭网给出局部反馈。首次操作不判节奏，按下录制就得到 N01「空弦」。便条提示“先拨一下”。GDD 的功放仍是中心道具，吉他只需简单外形与一处弦动效。录音素材是原创演奏片段，不能用电源嗡声冒充物理上自然产生的特定琴音。

**L02 / 靠近一点**。Recorder 对着喇叭的两个采样位置。拖动录音机位置或选择两个位置按钮，视觉波形和音色反馈不同；在标记区保持约 1 秒后点击录下，得到 N02「泛音」。这是空间听音与捕捉练习，不要求玩家识别绝对音高。长按可切换为单击开始／单击停止。

**L03 / 留住反馈**。功放增益旋钮提供可读弧形刻度，旋转进入较宽的稳定区；波形由散乱变为稳定，确认得到 N03「反馈尾音」。越过区间只改变音色，不惊吓爆音、不丢失进度。简化频谱图加形状提示。3/3 后门口听见自行车轮与雨水，门的灯光轻微变化。

关卡主色：红木、黑梁、钨丝暖光、冷门光。主要磨损在提手、舞台边和脚下。舞台、挂箱与夹层作为身份骨架，通道留空。13 号图是可读性优先的新提案；12 号保留为史料驱动的材料参考。

### 第二关 胡同 · 让声音开始走路

**H01 / 辐条**。拖一下自行车前轮，轮速可见。用已收单音对照辐条节奏，点击录制锁定一段预制 Riff，得到 R01「车轮」。表现从真实轮声过渡到原创拨弦乐句；必须明确这种音乐化处理，不暗示真实车轮会自动奏出和弦。

**H02 / 雨棚下**。点选两处排水／滴落声源，切换拾音位置，录下互补的节奏短句，得到 R02「雨线」。雨不是后续鼓轨的替代品；此处的产出是带节奏的旋律／贝斯乐句。背景雨声可单独调低，不占音乐轨。

**H03 / 接上这段磁带**。在雨棚干燥工作台上，用盘式机把两条波形的起点对齐。拖动磁带接点时听 A/B 对照，看瞬态标记；给出约八分音符宽的吸附区。确认得到 R03「巷口循环」，增加 Riff 层并开放唱片行。贴片接点是玩法示意，真实磁带物理与节拍处理在引擎中简化。

关卡主色：铅灰、旧砖、暗橄榄、小范围暖灯。地面是粗糙湿润；人走的路、停放的自行车、收起的线缆比满墙贴花更重要。

### 第三关 唱片行 · 让城市有骨架

**S01 / 翻到这一面**。翻开两个抽屉中的唱片套，选择有鼓点符号的那面，拖到左唱机／键盘选中确认，得到 D01「底鼓」。侧面小纸条来自虚构乐队，自制刊物和 CD-R 做背景细节；不使用真实唱片封面。

**S02 / 落针**。拖唱臂到宽阔的标记区，释放后自动在下一拍进入，得到 D02「军鼓与踩镲」。不做精确反应测试；需有大热区和一键替代。唱臂枢轴、唱盘旋转、针落下三个动作单独制作。

**S03 / 留一点底噪**。把中间 crossfader 推到自选位置，对比清晰鼓轨与唱片纹理；试听满意后确认得到 T01「表面噪声」。此处没有唯一正确音色，以听到明显变化、完成一次选择为条件。UI 明示“这是你的版本”。3/3 开放终章。

关卡主色：琥珀、旧纸、深木、少量纸媒彩色。唱片箱构成窄通道，操作台面周围留出可读空隙。

### 第四关 体育场 · 让这一卷被听见

**F01 / 装入四个声部**。Recorder 与主控台相接，把收藏映射到 Notes、Riff、Drums、Texture 四条总线。9 个样本由预制编曲模板组织：Notes 3 个形成旋律池；Riff 3 个做可切换乐句；2 个鼓轨可叠加；1 条纹理。四条总线不等于四个采样。

**F02 / 把位置让出来**。每条总线可静音、试听、调电平，主表头有形状与文字提示。所有类别至少进入一次且总电平处于提示区，允许确认；声音审美没有单一正确答案。自动电平辅助始终可用。失真是预制音色选择，不能由危险音量承担表现。

**F03 / REC**。按实体录音键，录一段约 8 小节的游戏内合奏；拍点和进度清楚，完成后磁带写入地点与“我的版本”。长镜头从近景控制台抬向人群与远舞台，镜头幅度可关闭。首版只保存游戏内参数和回放，不承诺导出 WAV。终章的场馆、人群与事件是虚构扩展。

## 音频制作起点

用于首轮原型的统一规格提案：84 BPM、4/4、2 小节循环约 5.714 秒；8 小节录制约 22.857 秒。音高素材先围绕 E 小调五声音阶 E–G–A–B–D，最终以原创乐句的听感决定，不从受版权保护的现成录音采样。

界面动作立刻有轻量机械反馈；音乐声部在下一小节边界进入，并使用短淡入淡出，避免相位与接缝突兀。录到的新声音先短暂独奏，再回到可调的整体环境。环境音、音乐总线、设备机械声、提示音分开控制。终章统一时钟，避免四关随意录下的原始音频直接叠加造成节拍失配。

首版可用原创合成音和占位演奏；实际循环清理、响度、限幅、音质与长时间听感仍需音频实现后验证，本轮 Figma 不证明混音可行。

## 首个 8–12 分钟测试切片

制作内容限于一个 Livehouse、三个近景互动、Recorder 目录和一个胡同入口。现有“30–60 秒空间游走”是其中的镜头可读性验证，不是整个可玩切片的时长。

1. 0:00–1:00：入场，看到功放、低舞台和门，读到便条。
2. 1:00–3:00：L01 通电与拨弦，首次录音确认。
3. 3:00–5:30：L02 换拾音位置，学会回听。
4. 5:30–8:00：L03 稳定反馈，3/3 后声音和出口响应。
5. 8:00–10:00：打开磁带目录，试听／静音，前往胡同入口，看到 Riff 的下一目标。

以上是节奏目标，不是已测得时长。没有计时压力；只想观察的人可自由停留。后续测试记录：首次找到功放的用时、首次自发理解录音的比例、求助次数、目录打开次数、是否能指出收集后的声音变化。

## 可读性与无障碍

不只靠红蓝颜色表达状态；焦点带轮廓和动词。字体清晰，手写字仅用于标签。字幕／声音图标／简化波形给出方向和捕捉条件；操作失败不靠刺耳声提示。允许关掉手持抖动、模糊、色溢，按键与提示可重绑定；必须提供拖动和长按的替代。短时间未操作时才出现一级提示，主动求助再显示动作示意。

## 保存与最小状态

保存 unlockedLocations、collectedSampleIds、completedInteractionIds、mixerSettings、recorderVersion、accessibilitySettings。每次成功录音和切换地点后保存。collection 与 interactionCompletion 分开；sample_id 去重；加载后由数据重新计算 0–3 进度与下一地点条件，不能只保存 UI 上的数字。

每个互动状态：未发现 → 已发现 → 正在操作 → 可录制 → 已保存。已保存状态可回到试听，但不得重复发首次奖励。焦点丢失暂停拖动／录制尝试，返回原状态；保存错误应明确提示重试，不假装写入成功。
