# v4 Style Lock

这轮把美术方向锁定为“晚 2000 年代地下音乐空间的纪录式长镜头”：空间是正在工作的房间，声音来源、线缆和材料磨损比装饰更先被读到。

## 规则

- 主色：纸张米白 `#E9E4D9`、氧化红 `#873E3A`、烟黑 `#242521`、荧光绿 `#8EA58D`、冷灯白 `#D9E5E1`。
- 材料：红漆木板、黑色角钢、夹板、补丁乙烯革、廉价吸音棉、纸质标签、半透明线缆套。
- 灯光：一个实用主光源加一个被污染的环境补光；角落要可读，不做镜面轮廓光。
- 镜头：16:9、视线高度、能看懂声音路径的长镜头；只在转场时轻微手持漂移。
- D22 / No Beijing 转译为虚构道具，不复制 logo、艺术家姓名或海报正文。

## 避免

废墟奇观、泛赛博霓虹、干净展厅、豪华录音棚、悬浮全息、空黑背景，以及没有玩法功能的怀旧装饰。
