# 《解忧录音室》（D-22）项目迭代 GDD

全面整合版。当前要做的切片在 [todo.md](todo.md)。

## 1. 游戏概述

游戏名称：《解忧录音室》（Jieyou Recording Studio）

游戏类型：沉浸式步行模拟 / 声音收集与独立音乐创作 / 轻度肉鸽

核心基调：梦核 × 现实主义。一边是具体的城市市井（菜市场、街头、叫卖、地下 Livehouse），一边是超现实、带一点记忆残缺的空间。

情感内核：像深夜听一首老牌地下乐队的最后一曲。可以是 D22 时期的噪声摇滚，也可以是 Lo-fi。孤独、温柔，带着时代的回声。

参考作品：

- 《Lushfoil Photography Sim》：写实和空间探索
- 《Season》：录音 + 步行模拟
- 《Despelote》：探索城市，再把它重建起来
- 《Many Nights a Whisper》：很短的一轮循环

目标平台：PC。VR 可选。

核心技术：

- 3D Gaussian Splatting，用老照片或线下激光点云重建空间
- 实时音频反应器，画面跟着声音动
- 声音演奏
- AI 生成音乐

## 2. 核心循环

```text
探索消失的城市（3DGS 空城 / 残影）
        │
        ▼  日夜、天气、因果
收集声音素材（鸽哨、雨夜雷声、市井残声）
        │
        ▼  带着核心声音残片
D22 / School 风格的地下工坊 / Playground
        │
        ▼  单人或双人混音：情绪注入，声部分工
现场演出与视听可视化（点云和灯光随振幅形变）
        │
        ▼
局外成长，进入下一座梦核城市
```

## 3. 核心机制

### 3.1 声音采集与解谜

玩家是一家神秘声音档案公司的采音师，被派到现实里已经消失的城市角落。

手里是一台老式收音设备。耳机里有立体声混响，声音随距离变轻。

录制判定：靠近声源，准心对准并保持 5 秒。声源移开，或中途被打断，这段录音带上杂音，不算数。

有些声音只在特定条件出现：白天的鸽哨、雨夜的积水、深夜的电台噪音。

### 3.2 声学回响遗痕城

场景是空城，没有活的 NPC，也不是一片死寂。

声学幽灵是过去居民留下的声音残影。拿着收音器靠近遗迹时，能听到当时的对话和市井喧嚣。遗迹可以是一辆旧自行车、一座发光的电话亭、一个摊位。

3DGS 负责梦核的样子。半透明的边和断开的轮廓，就是记忆被撕开的感觉。素材来自老照片和激光点云。

### 3.3 暗影与显形

暗影是一层暂时的视力。进入之后画面立刻变暗、变淡，不做淡入淡出。

人影只存在于暗影里。声源的模型在被录下来之前，也只在暗影里出现。青色电波只在暗影里、且只在这段声音还没录下时出现：一圈圈铺开；镜头移开时，仍停在屏幕边缘，标出声源的大致方向。退出暗影，电波立刻消失。

一段声音录清楚之后，青色电波不再出现，这段声音也不再从声源播放。声源的模型会留在正常视力里。没有录下来就退出暗影，模型再次隐去。声源留在原地，不拾取、不拿走，否则电波会失去目标。

走路仍是走出来的。其余能力不单独拾取：一段声音录完，对应能力自动学会。这条规则用于后来的每一种同类声音：鸽哨、磨刀、蛐蛐，以及再往后要收录的乐器。人影不因为录音进入正常世界。

## 4. 动态循环与轻度肉鸽

### 4.1 日夜与条件

一次探索里，时间和天气会变：清晨、斜阳、暴雨、深夜。

白天在 A 处录到的声音可以当音频钥匙。例如老锁的开锁声，到了夜间的 B 处，用它打开封存的声音记忆。

单局只有一天。

### 4.2 局外成长

一次探索是一个完整的长夜。时间耗尽，或记忆撕裂得太厉害，就回到录音室。

跨局保留：

- 玩家挑 3 个声音，永久留下，作为下一轮的创作基因
- 已解锁的近道、特殊收音卡带、设备升级（防杂音滤镜、远距离放大器）永久保留

叙事上，过去和现在叠在一起，声音把记忆叫醒。城市和场景可以随搜索进度解锁。

## 5. 多人与共享试验场

共享录音室是一个声音试验场。玩家可以请朋友进自己的地下录音室，把各自在不同城市录到的声音残片放进同一个库里，自由混。

双人可以组乐队。夜里回到 Livehouse，声音集齐之后开演。

沟通保持很少。不用语音把气氛冲掉。局内用音频信号弹，和老式对讲机的声音交流。

## 6. 音乐工坊与视听共振

### 6.1 地下工坊

收集到的声音汇进一间地下空间，质感靠近北京的 D22、School 这一类 Livehouse。

先选情绪：疲惫、燥热、怀念。再把收集到的素材交给算法，生成一段噪声摇滚、Ambient 或 Lo-fi。

### 6.2 视听可视化

播放这段音乐时，Livehouse 和外围城市的 3DGS 点云跟着音高、节奏和低频变化：鼓起、裂开、波动。现场感来自这里。

## 7. 演示版本

单城市 Demo。一座梦核城市里并着旧胡同、老厂区和深夜地下 Livehouse。

这一版要验证三件事：

- 3DGS 空城 + 声学幽灵
- 日夜循环里的声音解谜
- 单人 / 双人 Livehouse 的视听共振
